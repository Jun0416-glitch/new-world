Service Worker Safe Test (sw-test)

This page registers a sw-test/333 service worker stub (safe, local) for testing registration, caching and offline fallback without loading remote scripts.

Instructions:

  1. Start a local server from the repository root: python3 -m http.server 8080 (or similar).
  2. Open http://localhost:8080/sw-test/ in a browser launched with a fresh profile.
  3. Use DevTools → Application → Service Workers and Cache Storage to inspect registration and caches.
